# Contributing to Bridge

Thank you for your interest in contributing to the Claude Code ↔ Antigravity IDE Bridge!

## How to Contribute
1. Fork the repository and create your branch from `main` or `master`.
2. Ensure your changes follow python styling guidelines.
3. Verify that the server imports cleanly:
   ```bash
   python3 -c "import bridge.server"
   ```
4. Submit a Pull Request describing your changes, motivation, and verification steps.

## Code of Conduct
Please be respectful and collaborative. We aim to keep this a welcoming project for all contributors.
